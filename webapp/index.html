How this works. One pass, five stages: perception reports observations only (never a diagnosis); deterministic weather signals compute saturation, leaching, volatilisation and incorporation windows; retrieval pulls guideline text for and against every candidate cause; two-stage reasoning ranks a differential and picks the call; and a deterministic safety layer can overrule the model — every override is shown on screen.

This page runs the full deterministic Greenlight engine in your browser — the same rules-based reasoner, retrieval and safety net as the Python pipeline, verified to reproduce its decisions on all 25 evaluation scenarios. The LLM reasoning arm and live Open-Meteo weather live in the Python repo. Prices and thresholds are demo defaults; guideline chunks are placeholders to be replaced with cited GRDC / Agriculture Victoria text.
